# 5inrow

Крестики-нолики «5 в ряд» (Gomoku) на Python с графическим интерфейсом.

## Особенности
- Графический интерфейс на PySide6/PyQt.
- Возможность играть вдвоем по локальной сети (`network.py`).
- Одиночная игра против бота, использующего алгоритм Minimax с альфа-бета отсечением (`minimax_bot.py`).
- Агент на основе обучения с подкреплением (Reinforcement Learning) (`rl_agent.py`, `train_rl.py`).
- Возможность просмотра записей игр (`replay_viewer.py`).
